# TASK: INVITATION ACCEPTANCE WELCOME TRANSITION
# PROJECT: DESA SEHAT KENANGA

Saya ingin menambahkan sebuah UX transition khusus ketika
user menerima undangan melalui email dan menekan tombol
"Terima Undangan" / "Masuk ke Portal".

Saat ini flow sudah berfungsi:

EMAIL UNDANGAN
    ↓
User klik tombol "Terima Undangan"
    ↓
Website terbuka
    ↓
User langsung masuk ke dashboard

Secara functionality sudah benar.

Namun UX terasa terlalu tiba-tiba karena user langsung
dilempar ke dashboard.

Saya ingin menambahkan sebuah halaman / transition screen
yang terasa profesional, modern, friendly, dan cocok dengan
identitas website Desa Sehat Kenanga.
